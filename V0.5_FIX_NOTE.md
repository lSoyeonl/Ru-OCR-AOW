# v0.5 OCR packaging fix

This patch changes only the Windows packaging layer.

Main change:
- copies metadata for every installed PaddleX-known dependency using
  `paddlex.utils.deps.BASE_DEP_SPECS` / `DEP_SPECS`;
- follows PaddleOCR's official PyInstaller packaging strategy;
- pins PaddleOCR 3.7.0 and PaddleX 3.7.2 for reproducible CI builds;
- packaged EXE writes `ocr_self_test.json`;
- GitHub Actions prints that file before failing, so any remaining missing
  dependency will be visible by name.

Upload the files from PATCH to the repository root and replace existing files.
