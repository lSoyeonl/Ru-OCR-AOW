# v0.7.0 — MULTI TRANSLATOR

Добавлено:
- Azure Translator;
- DeepL API;
- Gemini API;
- DeepSeek API;
- автоматический fallback: Azure -> DeepL -> Gemini -> DeepSeek;
- отдельный выбор одного сервиса в настройках;
- F9 больше не скрывает причину отказа всех переводчиков;
- в строке состояния видно, какой сервис фактически выполнил перевод.

Ошибка DeepSeek HTTP 402 означает недостаточный баланс DeepSeek. В режиме Auto это не останавливает перевод, если настроен следующий провайдер.
