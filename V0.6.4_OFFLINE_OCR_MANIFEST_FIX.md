# v0.6.4 — Offline OCR manifest fix

Исправлена ошибка GitHub Actions:

    Could not determine local recognition model for vi.
    New dirs: []
    all cache: [..., PP-OCRv6_medium_rec]

Причина:
PaddleOCR может повторно использовать уже скачанную общую multilingual
recognition-модель для нескольких языков. Предыдущий prefetch-скрипт ошибочно
считал, что каждый новый язык обязан создать новую папку модели.

Изменения:
- prefetch теперь умеет повторно использовать PP-OCRv6_medium_rec /
  small / tiny, если модель уже находится в кеше;
- для Vietnamese сначала проверяется отдельная/Latin-модель, затем shared rec;
- runtime больше не принудительно задаёт ocr_version=PP-OCRv5, если используются
  явно указанные локальные модели разных поколений;
- self-test локальных моделей внутри EXE остаётся обязательным.

Если после этого сборка упадёт на
"Verify bundled OCR models inside packaged EXE",
это будет уже реальная проверка запуска конкретных локальных моделей.
