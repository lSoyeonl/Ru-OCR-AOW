# v0.6.5 — CPU oneDNN/MKLDNN fix

Исправляется фактическая ошибка Windows/CPU:

    NotImplementedError:
    ConvertPirAttribute2RuntimeAttribute not support
    [pir::ArrayAttribute<pir::DoubleAttribute>]

Что изменено:
- в PaddleOCR явно передаётся `enable_mkldnn=False`;
- используются обычные CPU kernels вместо oneDNN;
- `cpu_threads=4`;
- prefetch использует те же CPU-настройки;
- GitHub self-test теперь выполняет настоящее OCR inference, а не только
  инициализирует модели.

Это важно: предыдущая проверка могла быть зелёной, хотя F8 падал только
в момент predictor.run(). Новая проверка должна поймать эту ошибку ещё
на GitHub Actions.
