# v0.6.6 — visible OCR result

Проблема:
OCR уже мог успешно вернуть текст и уверенность (например ~95%), но главное
окно показывало только строку "OCR готов", а сам распознанный текст был виден
только во временном overlay. Из-за этого выглядело так, будто OCR ничего не
распознал.

Исправлено:
- на главной странице добавлено постоянное поле "Распознанный текст";
- результат F8 появляется там сразу, до DeepSeek;
- статус теперь показывает начало фактически распознанной строки;
- добавлена кнопка "Копировать распознанный текст";
- перед новым F8 старый результат очищается, чтобы его нельзя было перепутать
  с новым сканированием.

Для текста вида:
    要闻 公告 活动 新闻 媒体 攻略
нужно выбирать "Китайский (упрощ.)", потому что это упрощённые иероглифы.
