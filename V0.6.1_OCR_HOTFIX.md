# v0.6.1 OCR HOTFIX

Что исправлено:
- PaddleOCR теперь использует BOS как источник моделей вместо HuggingFace по умолчанию.
- Для интерактивного режима используется PP-OCRv5_mobile_det.
- Для китайского / традиционного китайского / английского используется лёгкий PP-OCRv5_mobile_rec.
- OCR выбранного языка подготавливается в фоне сразу после запуска.
- В интерфейсе отображается этап: загрузка модели / распознавание / автоопределение.
- Добавлена блокировка одновременной инициализации одной OCR-модели.
- Уменьшена избыточная обработка больших снимков.

Важно:
Первый запуск конкретного языка всё равно может занять время, потому что PaddleOCR
должен один раз скачать модель. После этого она кэшируется на компьютере.

DeepSeek:
Текущая v0.6.1 всё ещё требует DeepSeek API key в Настройки -> DeepSeek.
В следующей серверной v0.7 ключ будет вынесен на backend, чтобы пользователям
его не выдавать.
