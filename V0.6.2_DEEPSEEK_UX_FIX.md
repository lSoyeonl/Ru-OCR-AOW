# v0.6.2 — OCR/DeepSeek UX fix

Исправлено:
- результат OCR больше не скрывается за ожиданием DeepSeek;
- после OCR интерфейс сразу пишет, что распознавание завершено;
- если DeepSeek API key не задан, программа не выдаёт это как ошибку OCR;
- ручной перевод сразу объясняет, что нужно настроить DeepSeek;
- запрос к DeepSeek имеет ограничение ожидания 25 секунд и 1 повтор;
- OCR и перевод теперь воспринимаются как два отдельных этапа.

Важно:
эта версия по-прежнему использует личный DeepSeek API key из настроек.
В v0.7 перевод будет перенесён на сервер/Supabase, чтобы ключ не находился
на компьютерах пользователей.
