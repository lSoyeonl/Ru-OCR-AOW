# v0.6.3 — OFFLINE OCR

Главное изменение:
OCR-модели скачиваются не на компьютере пользователя, а заранее во время
GitHub Actions и включаются внутрь portable-сборки.

Зачем:
- после F8 программа больше не должна минутами ждать скачивания модели;
- готовый EXE не зависит от HuggingFace/BOS при обычном распознавании;
- GitHub перед выдачей артефакта запускает отдельный self-test именно локальных
  OCR-моделей внутри собранного EXE.

В сборку включаются:
- PP-OCRv5_mobile_det;
- китайская/английская mobile rec;
- Thai rec, выбранная PaddleOCR для lang=th;
- Vietnamese rec, выбранная PaddleOCR для lang=vi.

Для игрового использования рекомендуется выбирать язык вручную, а не «Авто».
